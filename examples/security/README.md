# 🛡️ Security Examples

This directory contains examples of how to use security-related steps in your pipelines.

## Examples included:

### 1. Fail2Ban Check (`fail2ban_example.py`)
Shows how to verify if an IP is currently banned by Fail2Ban analyzing system logs.

### 2. Nmap Scan (`nmap_example.py`)
Demonstrates how to perform port scans using Nmap (Requires `nmap` and `python-nmap`).

---
*Note: Some examples might require root access or specific system files.*
